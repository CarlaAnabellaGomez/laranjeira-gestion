# LARANJEIRA S.A.S. – Sistema de gestión

Página web del sistema de gestión (pedidos, clientes, cobranzas, stock, proveedores, gastos y usuarios).

- Datos y login: Firebase (proyecto `laranjeira-sas`).
- Publicación: GitHub Pages (rama `main`, carpeta raíz).
- `firestore.rules`: reglas de seguridad de la base de datos (copia de las que están cargadas en Firebase).
